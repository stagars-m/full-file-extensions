# BRAT release setup

1. Commit the repository contents to the default branch.
2. Create a GitHub release tagged `1.1.2`.
3. Use the release title `Full File Extensions 1.1.2`.
4. Attach these files individually from `release-assets/`:
   - `main.js`
   - `manifest.json`
   - `styles.css`
5. Publish the release.
6. In Obsidian, run **BRAT: Check for updates to all beta plugins**.

The release tag and the version in `manifest.json` must both be `1.1.2`.
